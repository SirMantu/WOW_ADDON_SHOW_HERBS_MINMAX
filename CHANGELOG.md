# Changelog

## 1.0.0

- Initial release: the game's interact icon is shown above the nearest herb, ore vein or skinnable corpse, and on nothing else.
- Herbs and ore are recognised by their object ID, so the addon works in every client language. Unknown nodes are learned the first time you gather them.
- Options panel with minimap button and `/shm`: herbs, ore and skinnable corpses can be switched on and off, and the icon size can be set from 10% to 100%.
- The game settings the addon changes are saved and restored when all options are switched off.
- `/shm live` prints the current target and game settings for troubleshooting.
